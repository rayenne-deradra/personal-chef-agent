# Personal Chef AI Agent

A simple AI-powered personal chef assistant developed for a ThirdUni assignment.

The agent creates recipes based on the ingredients available to the user. It can suggest meals, provide ingredients, and generate step-by-step cooking instructions.

## Features

* Generate recipes from available ingredients
* Provide cooking instructions

## Technologies

* Python
* AI Agent
* LLM

## Example

**Input:**
`Leftover cooked chicken and rice`

**Output:**
A personalized recipe using the available ingredients.
